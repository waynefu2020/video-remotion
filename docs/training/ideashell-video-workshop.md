# 内部培训：用 Agent + 代码做产品动效短视频

这是一份讲师手册，课上照着讲就行。参加的同事课前读完「课前准备」那一节即可。

- **时长：** 90 分钟（讲 25 分钟、演示 25 分钟、动手 30 分钟、答疑 10 分钟）
- **对象：** 市场、设计、产品和运营同学，不需要会写代码
- **用到的东西：** 本仓库的 `ideashell-video/` 和 Skill `.cursor/skills/ideashell-video/`

## 培训目标

上完课，每个人都应该能：

1. 说清楚这套做法跟剪辑软件有什么不同，什么时候该用它。
2. 在 Cursor 里用 `ideashell-video` Skill，从一句话主题出发，一路做到分镜、成片和封面。
3. 用自然语言提精确的修改意见，例如「第 3 秒的卡片晚 0.2 秒出来」「两边再留点空」。
4. 出片后照自检清单检查，尤其是小红书安全区。

## 课前准备（发给参加的同事）

- 装好 Cursor，并且能打开本仓库。
- **方式 A（推荐，免安装）：** 用 Cursor Cloud Agent。云端环境自带 Python、ffmpeg 和渲染依赖。
- **方式 B（本地）：** 需要 Python 3.10+ 和 ffmpeg。

  ```bash
  pip install pillow numpy
  brew install ffmpeg      # macOS；Windows 用 winget install Gyan.FFmpeg，并在 WSL 或 Git Bash 里运行 .sh 脚本
  cd ideashell-video && ./build_schedule.sh   # 能出 dist/ideashell-schedule.mp4 就说明环境好了
  ```

- 想好一个自己想做的功能点，一句话就行，例如「开会不用记笔记」「拍张白板就能变成待办」。

## 讲师课前检查

- [ ] 本地或 Cloud Agent 里跑通 `./build_schedule.sh`，并且记下耗时
- [ ] 准备好三条成片，在手机上用小红书预览过：`dist/ideashell-promo.mp4`、`dist/ideashell-memory.mp4`、`dist/ideashell-schedule.mp4`
- [ ] 准备一条参考视频链接（例如 TimeMind 那条），用来演示拆片
- [ ] 提前跑一遍演示脚本，把结果存一份。现场网络或渲染出问题时，直接放存好的结果

## 第一部分：为什么用代码做视频（25 分钟）

### 1. 看成片（5 分钟）

连放三条成片，不解说。然后问大家：你觉得这三条分别做了多久？改一版又要多久？

### 2. 这套做法是什么（10 分钟）

一句话：**视频是一个函数。给它一个时间 t，它画出那一帧。**

```
时间轴（文案 + 每个动作的时间点）
   ├─► 画面：每一帧用 Python 画出来 ─┐
   └─► 声音：配乐和音效用代码合成 ───┴─► ffmpeg 合成 MP4
```

要讲清楚的三点：

- **改得快：** 「游泳改成 19:30」「整体晚 0.3 秒」，都是改一个数字再重跑，十几秒就出新版。
- **品牌一致：** 字体、品牌橙 #FF4200、落版和安全区都写进了代码和 Skill，谁做出来都一样规范。
- **能复用：** 日程片里的「稿纸方格 → 标红 → 吹走 → 飞进卡片」可以直接拿给下一条片子用。

也要讲清楚它的边界：真人出镜、实拍素材、需要大量手工调色的片子，还是用剪辑软件。这套最适合 UI 动效、文字动画和信息图类的片子。

### 3. Skill 是什么（10 分钟）

打开 `.cursor/skills/ideashell-video/SKILL.md`，讲四块：

1. **硬规则：** 规格、不配人声、品牌色、禁用说法、小红书安全区。
2. **九步流程：** 问需求 → 拆参考 → 分镜（要等确认）→ 起项目 → 时间轴和画面 → 声音 → 出片自检（要等确认）→ 封面 → 交付。
3. **两个「停」点：** 分镜确认前不写代码；出片自检后再交付。这两个点是防止返工的关键。
4. **常见坑：** 每一条都是真实踩过的。拿两条讲故事：
   - **状态栏挡字：** 小红书会把视频铺到状态栏下面，所以现在每帧都要过 `xhs_safe`。
   - **底部黑边：** 缩小画面后最底下多出一条黑边，最后靠抽成片的帧才发现。所以自检一定要看成片。

Skill 放在仓库的 `.cursor/skills/` 下，打开仓库它就自动生效。想在别的项目里也用，可以把这个目录复制到 `~/.cursor/skills/`。

## 第二部分：现场演示（25 分钟）

在 Cursor 里新开一个 Agent 对话，下面的话照着输入。每一步停下来让大家看 Agent 做了什么。

### 第 1 步：给需求（3 分钟）

> 用 ideashell-video skill 做一条 15 秒的小红书竖屏视频，主题是「开会不用记笔记，会后自动出纪要」。不要配音。先给我分镜。

要点：Agent 会先给分镜表，不会直接写代码。跟大家解释，这就是第一个「停」点。

### 第 2 步：改分镜（4 分钟）

当场挑一处改，示范怎么提精确的意见：

> 开头钩子太长了，压到 2 秒以内；纪要那段加一个「3 条待办自动分给同事」的画面。

### 第 3 步：出第一版（8 分钟）

> 分镜可以，开始做。

讲解 Agent 在做什么：

- 用 `python3 new_video.py meeting_notes "开会不用记笔记"` 起项目
- 把分镜写进时间轴文件
- 一个段落一个段落地画，每画完一段出静帧检查

渲染的空档，打开 `meeting_notes_timeline.py` 给大家看：时间点全是具名常量，所以改起来很方便。

### 第 4 步：按反馈改（6 分钟）

示范三种常见的修改说法：

> 第二张卡片晚 0.3 秒出来，跟音效对齐。

> 两边太挤了，再多留点空间。

> 落版换成这张图的样子。（附截图）

### 第 5 步：自检和封面（4 分钟）

> 照 qa-checklist 自检一遍，再做 9:16 和 3:4 两张封面。

讲师备忘：现场渲染太慢的话，直接放课前存好的结果，讲解不中断。

## 第三部分：动手练习（30 分钟）

每人做一条 **12–15 秒**的竖屏片，主题用课前准备好的那句话。

**必须完成：**

1. 让 Agent 出分镜，至少改一次分镜再确认。
2. 出第一版成片。
3. 提至少两条具体的修改意见，出第二版。
4. 照 `qa-checklist.md` 自检，并把成片用小红书草稿在手机上预览一次。

**选做：**

- 拆一条你喜欢的参考视频（`reference-teardown.md`），把它的一个动效借用到你的片子里。
- 做封面。

**卡住了怎么办：**

| 现象 | 处理 |
| --- | --- |
| 渲染报字体找不到 | 用 `build_<slug>.sh` 跑一次，它会自动下载字体 |
| 文字叠在一起、一帧比一帧糊 | 在缓存图上直接画了，让 Agent 检查有没有漏掉 `.copy()` |
| 手机上顶部的字被挡住 | 最后一步漏了 `xhs_safe` |
| 声音太小 | 让 Agent 测一下 LUFS，调到 -14 左右 |
| Agent 的改动跟你想的不一样 | 说具体的秒数、元素和方向，附截图标出位置 |

## 第四部分：答疑和收尾（10 分钟）

挑两三个同事放一下他们的成片，大家一起照自检清单挑问题。最后说清楚：

- 新做的片子要提交到仓库，并在 `ideashell-video/README.md` 里加上分镜表。
- 踩到新坑时，把它补进 `SKILL.md` 的「常见坑」，下一个人就不会再踩。

## 附：好的修改意见长什么样

| 不好 | 好 |
| --- | --- |
| 节奏不太对 | 第 4–6 秒太拖，三张卡片的间隔从 0.7 秒缩到 0.4 秒 |
| 落版不好看 | 落版照这张图：logo 在上，口号用方格，「帮你做」三个格子用橙色 |
| 字太小 | 第二段卡片标题从 46 号改到 54 号，卡片高度跟着加 |
| 有点挤 | 两边太挤，左右各再留 60 像素 |
