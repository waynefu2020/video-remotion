# 动效语言选择

先找“变化”，再找画面。产品视频不是把功能点逐条贴在屏幕上，而是让观众看到输入如何变成结果。

## 六种可复用结构

### 1. 混乱变有序

适合：语音整理、日程、笔记、信息提取。

```text
混乱输入 → 标记噪音或错误 → 清理 → 重排 → 结构化结果
```

可用画面：方格逐字输入、红色标记、吹走、补位、飞入卡片、卡片落入日历。

### 2. 忘记变想起

适合：记忆、搜索、会议回顾、知识库。

```text
一个问题 → 穿过大量旧内容 → 找到关键记忆 → 带来源回答
```

可用画面：时间隧道、卡片墙、记忆星球、光束搜索、来源角标。

### 3. 一句话变行动

适合：待办、提醒、任务拆解、自动化。

```text
一句自然语言 → 拆成多条动作 → 补全时间与负责人 → 完成状态
```

可用画面：波形、词组拆分、标签吸附、待办卡片、时间和提醒弹出。

### 4. 多份内容变结论

适合：文件问答、合同、报价、报表。

```text
多种文件进入 → 扫描定位 → 高亮证据 → 汇总对比 → 给出结论
```

可用画面：文件飞入、扫描线、快速翻页、表格合并、最优项高亮。

### 5. 一个动作跨设备继续

适合：同步、多端产品、手表与手机联动。

```text
设备 A 开始 → 信息穿过空间 → 设备 B 接住 → 状态一致
```

可用画面：设备接力、同步光带、卡片穿屏、状态勾选。

### 6. 抽象价值主张

适合：品牌片、开场钩子、结尾口号。

```text
一句矛盾或痛点 → 视觉反差 → 品牌给出答案
```

可用画面：大字、留白、粒子聚合、颜色从灰到橙、安静后重音落版。

## 选型规则

- 一条 15–30 秒视频只选一个主结构，最多加一个辅助结构。
- 开头 2 秒必须出现痛点、反差或问题。
- 第一次结果应在总时长 40% 之前出现。
- 结尾前 3–5 秒留给品牌，不要把功能讲到最后一帧。
- 参考视频的作用是提供节奏和动效，不决定主题。

## 分镜颗粒度

每个镜头都要回答：

1. 观众看哪里？
2. 这一秒发生了什么变化？
3. 屏幕上究竟写哪几个字？
4. 哪一个声音告诉观众动作完成？

答不出来的镜头不要进入分镜。
