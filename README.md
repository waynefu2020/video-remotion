# 闪念贝壳竖屏动效视频

这个仓库是一套能直接制作竖屏产品短视频的 Skill。它不只包含说明，还带有可运行的渲染底座、音乐音效、品牌素材、工程生成器、成片检查和三个案例。

不做读链接、拆文案、看点赞评论。

完整 Skill 在 [product-motion-video/](product-motion-video/)；入口是
[product-motion-video/SKILL.md](product-motion-video/SKILL.md)。Cursor、Grok、Claude（Opus 5.5）都使用这一份。可直接上传的单文件包在 `dist/product-motion-video.skill`。

运营同事只需要说：

> 使用 product-motion-video Skill，帮我做一条 15 秒的小红书竖屏视频。主题是「开会不用记笔记，会后自动出纪要」。先给我分镜，确认后再制作。

培训讲义在 [docs/training/ideashell-video-workshop.md](docs/training/ideashell-video-workshop.md)。

已有成片在 `ideashell-video/dist/`：

- `ideashell-schedule.mp4`：28 秒，稿纸方格 → 待办 → 日历
- `ideashell-promo.mp4`：30 秒宣传片
- `ideashell-memory.mp4`：32 秒记忆能力

`ideashell-video/` 是三个已验证案例的源代码和成片，供 Skill 复用。
