# 出片自检清单

所有检查都基于 `dist/` 里的成片，不看渲染前的静帧。

## 抽帧

```bash
F=dist/ideashell-<slug>.mp4
for t in 0.5 3 6 9 12; do ffmpeg -v error -y -ss $t -i $F -frames:v 1 /tmp/qa-$t.png; done
ffmpeg -v error -y -i $F -vf "fps=2,scale=180:-1,tile=8x8" -frames:v 1 /tmp/qa-sheet.png
```

## 规格

- [ ] `ffprobe` 显示 1080×1920、30 fps，时长和分镜一致
- [ ] 有音轨；响度约 -14 LUFS（`-af ebur128`）
- [ ] 全片没有人声

## 小红书安全区

最后一帧必须经过 `xhs_safe`。抽帧检查以下几点：

- [ ] y < 260 的范围里没有文字或关键元素（状态栏和返回、分享按钮在这里）
- [ ] 左右各 150px 内没有关键文字（裁切约 70px，再留一点余量）
- [ ] y > 1810 的范围里没有关键内容（作者名和标题栏在这里）
- [ ] 画面四边没有黑边。用下面的命令检查，打印的颜色应该都是背景色：

```bash
python3 -c "
from PIL import Image; im=Image.open('/tmp/qa-6.png')
print([im.getpixel(p) for p in [(540,5),(540,1915),(5,960),(1075,960)]])"
```

## 画面

- [ ] 用户确认过的文案逐字对得上，没有错别字、半角全角混用或标点漏格
- [ ] 每个元素的进场和离场都完整，没有闪一下就消失、叠影或残影
- [ ] 飞行中的元素在最上层，不被卡片挡住，也不透出底下的格子
- [ ] 同类元素的对齐、间距和字号一致
- [ ] 落版和用户给的图一致：logo、标题、口号、设备标签、应用商店提示
- [ ] 没有「超过百万用户」这类说法；品牌橙是 #FF4200

## 声音

- [ ] 每个关键动作都有对应音效，并且卡在动作那一帧上（打开成片听，不看波形）
- [ ] 结尾音乐自然收尾，不戛然而止
- [ ] 没有爆音：`max_volume` 不超过 -0.5 dB

```bash
ffmpeg -i $F -af volumedetect -f null - 2>&1 | grep max_volume
```
