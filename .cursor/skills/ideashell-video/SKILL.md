# 闪念贝壳竖屏动效视频

操作手册不在这里。完整流程、硬规则和自检清单在 `ideashell-video/PLAYBOOK.md`，配套说明在 `ideashell-video/playbook/`。

那份手册不绑定 Cursor。Grok、Claude（Opus 5.5）和其他能跑命令的 Agent 用的是同一份，规则只维护在那一处。

开始做视频时：读完 `ideashell-video/PLAYBOOK.md` 和它链接的文件，严格按顺序执行。标了「停」的步骤要等用户确认。
