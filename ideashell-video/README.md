# 闪念贝壳 30 秒竖屏宣传片

用代码生成的 1080×1920、30 fps、30 秒宣传片。画面是 Python + Pillow 逐帧绘制的 UI 动效，配乐和音效全部由 numpy 合成，最后用 ffmpeg 合成 MP4。成片在 `dist/ideashell-promo.mp4`。

## 分镜

| 时间 | 段落 | 内容 |
| --- | --- | --- |
| 0–2s | 开场钩子 | 「想法很多，记下的很少，想透的更少。」碎片想法飘走淡出 |
| 2–9.4s | 记 | 手表录音，碎碎念逐词弹出。口头禅逐个标红弹走（音调递增连击），「周四，不对」按改口删掉，文字收紧并显示「39 字 → 26 字」，最后长成一条带标题、标签和待办的笔记 |
| 9.4–15.7s | 场景 01 会议 | 「下午和 Allen 有个会，帮我准备一下」→ 拉远露出 1,000 张笔记组成的笔记墙，扫描、筛选，4 条相关记忆亮起飞出 → 会议准备卡，每条要点标注来源 |
| 15.7–20.6s | 场景 02 客户对话 | 一小时客户录音，高亮关键原话 → 橙色「发现机会」卡片 |
| 20.6–25.6s | 场景 03 待办 | 在手表上随口说一句 → 拆成 3 条带时间的待办，「到点提醒你」 |
| 25.6–30s | 收尾 | Logo、闪念贝壳、「帮你记，一起想。」、「让每一个被记下的想法，都有下一步」 |

每个场景顶部有「记 · 录下来 → 想 · 一起想」进度条，跟着剧情依次点亮。品牌橙取自 logo（#FF4200）。

## 重新生成

依赖 Python 3、Pillow、numpy 和 ffmpeg。

```bash
pip install pillow numpy
./build.sh
```

`build.sh` 会先下载 Noto Sans SC 字体（约 34 MB，不进仓库），再依次生成音频、渲染画面、合成成片。

- 改时间点：`timeline.py`，画面和音效共用这一份时间轴
- 改画面和文案：`render.py` 里的 `scene_*` 函数
- 改配乐和音效：`audio.py`
- 碎碎念每个短语的出现时间来自 `assets/voice/capture.json`（`voice.py` 用离线 TTS 生成的节奏参考，成片里没有人声）
- 只出几张静帧检查排版：`python3 render.py --stills 5.8 12.8 29.5`，输出到 `out/`

`assets/` 里是产品截图素材（手表、手机、Mac 和 logo）。

# 闪念贝壳 32 秒「记忆能力」竖屏片

同样的做法（1080×1920、30 fps、无人声），直接展示两件事：从 1,000 条笔记里找到对应的记忆来回答；上传的文件都能问答。成片在 `dist/ideashell-memory.mp4`。

## 分镜

| 时间 | 段落 | 内容 |
| --- | --- | --- |
| 0–4.6s | 开场：时间隧道 | 打字提问「去年王总说的预算，是多少来着？」→ 文字碎成粒子，粒子变成上千张笔记卡，组成隧道，镜头穿行回溯，月份从 2026.10 倒数到 2025.11 → 急停、静音一拍 → 那条录音卡飞到眼前，高亮「80 万」→「你忘了的，它都记得。」 |
| 4.6–15.2s | 01 · 1000 条笔记 | 1,000 个点组成的记忆星球。提问「下周和王总谈续约，我该注意什么？」→ 光束在星球里跳 4 个节点 →「回忆与行动」卡（还原产品 UI）→ 带来源角标的回答，「跨越 11 个月 · 3 次会议 · 4 条记忆」→ 星球旋转，连答 3 个生活问题 |
| 15.2–27.2s | 02 · 上传的文件，都能问 | PDF、Word、PPT、Excel、图片、录音、网页链接依次飞入、扫描、被 logo 吞下 → 86 页合同手风琴翻到第 47 页，高亮违约条款 → 三份不同格式的报价汇成对比表，标出最低价和交付最快 |
| 27.2–32s | 收尾 | 星球坍缩成 logo，闪念贝壳、「帮你记，一起想。」 |

## 重新生成

```bash
./build_memory.sh
```

- 时间轴：`memory_timeline.py`（画面和音效共用）
- 画面：`memory_render.py`（复用 `render.py` 的绘图工具），静帧检查：`python3 memory_render.py --stills 2.6 9.8 26`
- 配乐和音效：`memory_audio.py`（复用 `audio.py` 的乐器和音效）

# 闪念贝壳 28 秒「说话乱七八糟，日程井井有条」竖屏片

参考 TimeMind 的稿纸方格风格：一个字一格逐字打出，口头禅和改口标红后被吹走，剩下的字补位，再飞进待办卡。1080×1920、30 fps、无人声，成片在 `dist/ideashell-schedule.mp4`。

## 分镜

| 时间 | 段落 | 内容 |
| --- | --- | --- |
| 0–8s | 第一段 | 「嗯，那个，明早九点，啊不是，十点跟老板过方案，然后那个，PPT今晚得改完。」→ 标出 3 处口头禅、1 处改口 → 吹走补位 → 两张待办：跟老板过方案（明天 10:00，提前 15 分钟提醒）、改 PPT（今晚 22:00 前） |
| 8–15.9s | 再说一段 | 更长更乱的一段，7 处标红连击 → 4 张待办：妈妈生日、订蛋糕、游泳（每周二、四 19:30，每周重复）、交房租 |
| 15.9–20.2s | 稿纸变日程表 | 6 项待办缩成标签，方格变形成本周日历，待办按日期和时间落位 →「说得再乱，日程也井井有条。」 |
| 20.2–28s | 口号与落版 | 「呃，就，帮你记，帮你做」吹走口头禅，「帮你做」亮橙 → logo、闪念贝壳、任何设备随时同步、iPhone / Android / Mac / Windows / Apple Watch、应用商店搜「闪念贝壳」 |

## 重新生成

```bash
./build_schedule.sh
```

- 时间轴和文案切分：`schedule_timeline.py`（画面和音效共用）
- 画面：`schedule_render.py`，静帧检查：`python3 schedule_render.py --stills 3.9 19 26`
- 配乐和音效：`schedule_audio.py`
