# 闪念贝壳 30 秒竖屏宣传片

用代码生成的 1080×1920、30 fps、30 秒宣传片。画面是 Python + Pillow 逐帧绘制的 UI 动效，配乐和音效全部由 numpy 合成，最后用 ffmpeg 合成 MP4。成片在 `dist/ideashell-promo.mp4`。

## 分镜

| 时间 | 段落 | 内容 |
| --- | --- | --- |
| 0–2.5s | 开场钩子 | 「想法很多，记下的很少，想透的更少。」碎片想法飘走淡出 |
| 2.5–7.5s | 记 | Apple Watch 录音，实时转写；「嗯… 那个 ……」口头禅标红划掉，整理成干净的一句话 |
| 7.5–8.5s | 过渡 | 「记下来，再和你一起想。」 |
| 8.5–14s | 场景 01 会议 | 「下午和 Allen 有个会，帮我准备一下」→ 查看日程 / 了解联系人 / 找到相关记忆 → 会议准备卡 |
| 14–19.5s | 场景 02 客户对话 | 一小时客户录音，高亮关键原话 → 橙色「发现机会」卡片 |
| 19.5–25s | 场景 03 待办 | 在手表上随口说一句 → 拆成 3 条带时间的待办，「到点提醒你」 |
| 25–30s | 收尾 | Logo、闪念贝壳、「帮你记，陪你想。」、「让每一个被记下的想法，都有下一步」 |

每个场景顶部有「记 · 录下来 → 想 · 一起想」进度条，跟着剧情依次点亮。品牌橙取自 logo（#FF4200）。

## 重新生成

依赖 Python 3、Pillow、numpy 和 ffmpeg。

```bash
pip install pillow numpy
./build.sh
```

`build.sh` 会先下载 Noto Sans SC 字体（约 34 MB，不进仓库），再依次生成音频、渲染画面、合成成片。

- 改时间点：`timeline.py`，画面和音效共用这一份时间轴
- 改画面和文案：`render.py` 里的 `scene_*` 函数
- 改配乐和音效：`audio.py`
- 只出几张静帧检查排版：`python3 render.py --stills 5.8 12.8 29.5`，输出到 `out/`

`assets/` 里是产品截图素材（手表、手机、Mac 和 logo）。
